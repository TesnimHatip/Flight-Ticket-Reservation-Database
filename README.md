# Flight Ticket Reservation Database System

## Project Overview

This project was developed as part of the Database Management Systems course at Selçuk University in 2025.

The project focuses on designing and implementing a relational database for a flight ticket reservation system using Microsoft SQL Server.

## Technologies Used

- Microsoft SQL Server
- T-SQL (Transact-SQL)
- SQL Server Management Studio (SSMS)
- Relational Database Design

## Project Features

- Database requirements analysis
- Entity-Relationship (ER) modeling
- Database normalization (1NF, 2NF, 3NF)
- Primary and foreign key relationships
- Database tables for passengers, flights, airlines, airports, bookings, payments, tickets, and seats
- SQL queries using JOIN, GROUP BY, SUM, COUNT, and AVG
- Stored procedures for passenger registration, payment status updates, and reservation retrieval
- Triggers for database operations

## Database Design

The database manages information about passengers, flights, reservations, airlines, airports, payments, tickets, and available seats.

## Project Documentation

The repository contains the academic project report, including database diagrams, SQL examples, implementation screenshots, and query results.

The complete standalone SQL source files are not included in this repository.
